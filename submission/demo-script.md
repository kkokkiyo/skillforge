# 3분 데모 대본

팀명 임시안 TraceMakers / 서비스 SkillForge. 실제 UI 화면 녹화를 권장합니다. 아래는 녹화 지시서이며 녹화 완료 증거가 아닙니다.

| 구간 | 화면·동작 | 설명 |
|---|---|---|
| 00:00-00:20 | 콘솔과 문제 정의 | 같은 환불을 매번 추론하는 비용, 고정 자동화 유지보수, 금전 변경 검증 문제 |
| 00:20-00:50 | 새 정상 주문, Live + 직접 실행 | 실제 Nemotron 도구 호출 6단계. 키와 운영자 토큰은 녹화 전에 숨김 |
| 00:50-01:15 | live 출처 후보 상세 | 서로 다른 주문 성공 5건의 run ID와 일반화된 참조. 과거 주문 ID를 복사하지 않음 |
| 01:15-01:35 | Validation 결과와 활성화 | 생성에 쓰지 않은 30개 사례, 독립 oracle. 운영자 활성화 필요 |
| 01:35-01:55 | 새 정상 주문, auto 실행 | 모델 호출 없이 동일한 gateway로 처리. 수동 워크플로와도 비교 |
| 01:55-02:20 | 고액 승인 시나리오 | 승인 대기, 운영자 단회 승인, 최신 상태 재검사. 실제 결제 아님 |
| 02:20-02:40 | 정책 변경 시뮬레이션 | ACTIVE가 STALE로 바뀌며 이전 절차의 신규 자동 실행 제외 |
| 02:40-03:00 | 평가표와 한계 | 표본·오류 포함. 429가 많은 결과로 속도 향상을 주장하지 않음. OpenShell·Skill API 미확정 공개 |

## 녹화 전

1. 정상·고액 시나리오를 새 주문으로 준비합니다. 이전에 환불된 주문을 재사용하면 정상 데모도 차단됩니다.
2. 대표 live 후보와 validation 결과가 보이는지 확인합니다.
3. 운영자 토큰 입력 후 비밀번호 입력 칸이 비었는지 확인합니다.
4. Live 호출 장애가 있으면 녹화 재생임을 명시하고 저장된 trace를 보여줍니다. Mock을 live로 표시하지 않습니다.
5. 정책 변경은 마지막에 수행합니다. 복구 시 현재 정책에 맞는 새 후보를 검증·활성화해야 합니다.
