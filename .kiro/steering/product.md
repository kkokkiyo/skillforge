# 제품 방향

SkillForge의 고객은 커머스 CS 운영자와 에이전트 개발팀이다. 반복 환불 처리의 모델 호출 낭비와 변경 작업의 불투명성을 한 콘솔에서 다룬다. 최초 업무 탐색은 Nemotron, 재사용은 검증된 선형 실행기, 환불 허용은 결정적 정책 검사로 분리한다.

데모의 목표는 trace → candidate → verification → active → safe reuse를 눈으로 확인하는 것이다. 최초 발명·일반적 안전 보장·실고객 도입 성과를 주장하지 않는다. 자세한 범위는 requirements.md가 기준이다.
