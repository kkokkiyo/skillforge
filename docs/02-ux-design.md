# 화면 디자인 — 증거가 보이는 운영 콘솔

## 사용자와 핵심 행동

고객용 채팅 서비스보다 **CS 운영자가 처리·검증·승인을 이해하는 콘솔**을 만든다. 첫 화면의 질문은 “이 요청은 어떻게 처리됐고, 이 절차를 다시 써도 되는가?”다. 심사자는 30초 안에 Before / Compile / After를 찾을 수 있어야 한다.

내비게이션은 실행, 절차 라이브러리, 평가의 3개. 승인 대기는 실행 화면과 상단 알림에서 바로 접근한다. MVP에 로그인 마케팅 페이지·조직 설정·복잡한 플로 편집기를 만들지 않는다.

후보 상세: 왼쪽 source trace 목록, 가운데 실제 도구 순서 및 인자 출처, 오른쪽 validation 사례/실패 이유. 하단 활성화 버튼은 VERIFIED 상태에서만 켠다. 승인 버튼과 워크플로 활성화 버튼은 다른 문구·다른 endpoint를 사용한다.

## 사용자 흐름

1. 정상 사례 선택 → ReAct 실행 → 각 단계 완료 상태와 호출 수 표시.
2. 기록 탭에서 후보 만들기 → 묶인 source ID, 전체 순서, support 확인.
3. 검증 실행 → 정상/차단/승인 사례 결과 → 운영자 활성화.
4. 새 주문 입력 → 재사용 경로 배지 → Before/After 비교.
5. 중복 또는 정책 변경 사례 → 환불을 실행하지 않은 이유 표시.

초기 데모용 discovery 데이터는 미리 준비할 수 있지만 “실제 API로 수집한 합성 업무 기록”과 수집 시각을 표시한다. 즉석에서 기록이 저절로 학습된 듯한 가짜 애니메이션을 만들지 않는다.

## 시각 언어

| 요소 | 값 / 원칙 |
|---|---|
| 배경 / 카드 | #F6F8FA / #FFFFFF |
| 본문 / 보조 | #17212B / #52606D |
| 강조 | #2F6B16, NVIDIA 로고와 공식 제휴 표시 사용 안 함 |
| 정보 / 경고 / 차단 | #175CD3 / #92400E / #B42318 |
| 간격 | 4·8·12·16·24·32px |
| 글꼴 | 시스템 한국어 sans-serif, 숫자 tabular-nums |
| 크기 | 본문 14~16px, 제목 24px, 핵심 숫자 28px |
| 컴포넌트 | 얇은 경계, 8px radius, 작은 그림자 또는 없음 |

색만으로 상태를 전달하지 않는다. 체크/대기/차단 아이콘과 한글 텍스트를 함께 사용한다. 본문 대비 4.5:1 이상을 구현 시 확인한다. 1440px 기준 24px 여백, 240px 사례 패널 / 유동 실행 영역 / 320px 근거 패널. 1280px에서는 근거 패널 drawer, 768px 이하는 세로 쌓기. reduced-motion 설정을 따른다.

## 상태별 문구

| 상태 | 문구와 행동 |
|---|---|
| 기록 없음 | “첫 요청을 실행하면 처리 기록이 쌓입니다.” / 사례 실행 |
| 후보 부족 | “독립 성공 기록 5건이 필요합니다.” / 현재 건수 표시 |
| 모델 오류 | “모델 응답을 받지 못했습니다. 환불 상태를 확인하세요.” / run 상세 |
| 승인 대기 | “500,000원 이상 환불은 운영자 승인이 필요합니다.” / 바인딩 정보 |
| 정책 변경 | “검증 이후 정책이 바뀌어 이 절차를 중지했습니다.” / 재검증 |
| 쓰기 후 오류 | “환불 결과 확인 중입니다. 다시 실행하지 마세요.” / 상태 조회 |
| 지표 없음 | “미측정” / 평가 실행 |
| 재생 모드 | “기록 재생 · 실시간 모델 호출 아님” / 원본 수집 시각 |

## UI 완료 기준

키보드로 실행·탭·승인·상세 닫기가 가능하다. 스크린리더용 live region은 단계별 완료를 과도하게 반복하지 않는다. 실패·차단과 성공 지표를 같은 화면에서 확인할 수 있다. 실행 중 reset/중복 실행을 막고, SSE 재접속 시 이벤트가 중복 표시되지 않는다. 스크린샷 데이터도 목표 수치 대신 실제 fixture 또는 미측정 배지를 사용한다.


## 정책 변경 화면 (2026-09-26)

워크플로 랩 상단에 현재/변경 승인 금액, 영향 비교 버튼, 바뀐 사례의 전후 판정, 위험 변경/정상 오차단 지표를 표시한다. 적용은 성공한 미리보기 후에만 가능하다. 새 후보는 아래 라이브러리에서 검증·활성화한다. 35만원 반품 버튼으로 50만원→30만원 정책의 차이를 재현한다. 합성 replay와 live 모델 실행을 별도 표시한다.
