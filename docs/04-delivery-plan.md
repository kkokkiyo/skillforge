## 제출 체크

- 팀명·팀장·팀원 2~5인 확정, 연령 조건 확인. 개인 지원 문구와 팀 지원 문구가 함께 있으므로 팀 없는 상태는 주최 측 확인.
- 각 팀원이 개별 신청해야 한다는 제공 안내 확인.
- 개인정보 동의는 본인이 결정하고 제출. 마케팅 동의는 선택 항목으로 구분.
- GitHub 링크만 폼에 붙이는 대신, 제공 안내대로 프로젝트명·링크를 담은 PDF/Word를 업로드.
- 파일 1개, 최대 1GB. 실제 마감 시각, 링크 공개 범위, 영상 접근 확인.
- 서비스명, Problem 약 300자, Solution 약 500자, 실제 사용 스택 일치.
- 실측 수치·live run·미구현 기능·synthetic 데이터가 문서와 영상에서 일치.
