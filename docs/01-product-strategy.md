# 주제 선택과 예선 설득 전략

## 결정

**SkillForge: 성공한 환불 처리 경험을 검증된 실행 절차로 바꾸는 에이전트 운영 콘솔**을 만든다. 부제는 “반복 업무는 적은 추론으로, 변경 작업은 근거와 함께”. 사용자는 커머스 CS 운영자, 2차 고객은 업무 에이전트 개발팀이다.

사용자 첨부안의 방향은 좋지만, 범용 프레임워크로 발표하면 문제와 차별점이 추상적이다. 주문 조회·주소 변경·환불을 모두 지원하기보다 **반품 수령 후 전액 환불** 한 가지에 집중한다. 수동 승인·중복 요청·정책 변경이라는 예외까지 완결해야 실용성이 보인다.

## 후보 비교 — 팀의 판단이며 합격 확률 예측이 아님

| 후보 | 장점 | 이번 일정의 약점 | 결정 |
|---|---|---|---|
| 범용 ReAct-to-Workflow 컴파일러 | 교육과 기술 연결이 선명 | 범용 인자 추론과 검증이 큼, 고객 가치 설명 어려움 | 환불 한 도메인으로 제한 |
| 보안 환불 처리 + 실행 경험 재사용 | 상태 변화·속도·차단 근거를 한 데모로 비교 가능 | CS 챗봇으로 오해받을 수 있음 | 채택 |
| IT 장애 대응 runbook 에이전트 | 산업 가치와 안전 실행 연결 좋음 | 실제 장애 환경·회복 검증 구축 부담 | 확장 후보 |
| 문서/RAG 사내 도우미 | 빠른 구현 | 실행·안전·최적화 차별점이 약함 | 보류 |

## 사용자의 문제를 검증하는 방법

“업무가 반복되어도 매번 같은 조회·판단을 다시 한다”는 가설을 출발점으로 삼는다. 실제 처리량·비용·CS 담당자 경험은 아직 확보되지 않았다. 9/21까지 커머스 운영 경험자 2~3명에게 인터뷰를 **팀이 직접** 진행한다. 자동 연락은 하지 않는다.

질문: 가장 반복되는 환불 유형은? 건당 어떤 시스템을 확인하는가? 자동 처리 불가 조건은? 승인·감사에 남겨야 할 근거는? 응답은 익명 요약하고 합성 데모 정책과 실제 업무 사실을 구분한다. 확보 못 하면 “운영 가설을 합성 환경에서 검증한 프로토타입”으로 발표한다.

## 차별점의 정직한 범위

Agent Workflow Memory 등 경험에서 절차를 유도하는 선행 연구가 있다([R09](06-references.md)). “세계 최초”, “스스로 학습하는 범용 에이전트”는 쓰지 않는다. 우리의 기여는 **업무 상태와 인자 출처가 보존된 선형 DSL, 별도 검증 사례를 통한 승격, 정책·버전 검사, 비교 증거 UI**의 통합 구현이다. 신경망 학습이나 파인튜닝이 아니다.

“수동 워크플로면 충분한가?”에는 **이 도메인에서는 충분할 수 있다**고 답한다. 따라서 수동 워크플로도 baseline에 넣는다. 자동 생성이 수동보다 빠르다는 주장이 아니라, 실행 기록에서 재사용 후보와 근거를 만드는 과정의 가치를 평가한다. 자동화 시간 절감도 실측 전에는 주장하지 않는다.

## 원안 수정 이유

- 빈도가 높은 tool 이름만으로 인자 연결과 안전성이 증명되지 않는다. argument provenance와 타입 검사 추가.
- 성공 기록만 모아서 성공률을 계산하면 생존자 편향이 생긴다. 실패 포함 원시 기록 보존, 별도 검증 집합 사용.
- 임의 가중 Promotion Score 대신 명시적 통과 조건을 사용한다. 원안 예시 수식은 최대값·임계값 해석도 불명확하다.
- PrefixSpan의 건너뛰는 부분수열은 필수 검사를 생략할 수 있다. MVP는 전체 선형 순서가 같은 기록끼리 묶는다.
- 환불 실행 이후 무조건 ReAct로 fallback하면 중복 환불 위험이 있다. 쓰기 시도 이후는 상태 확인과 조정 경로로 이동한다.
- Skill 문서는 실행 권한이 아니다. 정책은 backend에서 다시 검사한다.
- 13일 계획을 9/20~9/28 일정으로 축소한다. 미래 본선 미션에 현재 주제가 그대로 쓰인다고 가정하지 않는다.

## 최소 완성 범위

반품 수령/금액/정책 조회 → 견적 → 모의 환불 → 결과 확인의 완결 흐름. 실제 NVIDIA 호출, trace 기록, 최소 5개 독립 성공 기록의 후보 유도, 별도 사례 검증, 운영자 활성화, 재사용, 금액 승인, 중복·정책 변경 차단, A/B/C 평가 및 콘솔.

추가 업무·임베딩 라우터·벡터 DB·멀티에이전트·임의 DAG·PrefixSpan·범용 코드 생성·실결제·대규모 학습은 다음 버전으로 미룬다.
